# BankEdge AI - Center Manager (Gurugram)

Automated Android app project for BankEdge Gurugram (Office No. FF9, Spanish Court, Near Krishna Chowk, Palam Vihar, Sector 2).

### How to generate APK using GitHub:
1. Create a new GitHub repository on your phone or PC.
2. Unzip this package and upload all files (or push the repository).
3. GitHub Actions will automatically start building the APK under the **Actions** tab.
4. Download the compiled `BankEdge-AI-Gurugram` artifact and install `app-debug.apk` directly on your Android smartphone.
